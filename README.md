## How it works

`main.ts` writes the lead verbatim — 146 characters, no trailing newline — to `/output/entry.txt`. No dependencies, no network, no clock, no randomness.

Run it:

```sh
node main.ts
```

For local testing, override the output directory:

```sh
OUTPUT_DIR=/tmp/test-output node main.ts
```
